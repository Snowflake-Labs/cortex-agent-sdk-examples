=== 4. The explicit restUrl + tokenProvider form ===
  reply: EXPLICIT_OK

=== 5. Credential-shape rules the SDK enforces ===
  restUrl without tokenProvider:
    API mode api.restUrl requires api.tokenProvider so the SDK can refresh expired Snowflake session tokens
  tokenProvider without restUrl:
    API mode api.tokenProvider requires api.restUrl
  a bare api.token:
    API mode does not support api.token; pass api.tokenProvider so the SDK can refresh expired Snowflake session tokens
  OAUTH with no credential source:
    API mode api.authTokenType sessionless token types require a directly supplied credential via api.tokenProvider. Tokens obtained through a Snowflake connection profile are session tokens and must use authTokenType: "SNOWFLAKE_TOKEN".
  unknown authTokenType:
    API mode api.authTokenType must be one of: KEYPAIR_JWT, OAUTH, SNOWFLAKE_TOKEN
